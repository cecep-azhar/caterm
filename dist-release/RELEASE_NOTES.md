## What's Changed in CATerm v2.1.18

### 🌟 Pro Ambient Lighting & RGB Chroma Engine
- **Pro Ambient Underglow Engine**: Underglow lighting around terminal window frame.
- **Multiple Color Modes**:
  - **App Brand**: Dynamic theme-reactive accent glow matching current active CATerm palette.
  - **Solid Hex**: Custom user-defined HEX color code picker.
  - **RGB Chroma Rainbow**: Fluid RGB cycle across full spectrum.
  - **Aurora Drift**: Organic, shifting polar aurora gradient aesthetics.
- **GPU-Accelerated Animations**:
  - `Static`, `Breathing / Pulse`, and `Wave` animations running smoothly on CSS/compositor layer.
- **Granular Control**: Configurable opacity, blur radius, spread distance, and animation speed sliders.

### 🎨 UI/UX & Layout Enhancements
- AI Chat layout polish and responsive fix.
- Settings modal reorganization for Ambient Lighting controls.

### 🔒 Maintenance & Security
- Updated internal dependencies.
- Bumped Tauri/Cargo versioning to `2.1.18`.
