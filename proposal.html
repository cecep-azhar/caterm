2. CATerm Sync Cloud: Monetization & Pricing

The core local desktop application remains 100% Free and Open Source (MIT). Monetization focuses on convenience, multi-device synchronization, and team collaboration via an official managed cloud.

Subscription Model (B2C & B2B)

  • Trial/Entry: $1 for the 1st Month (Lowering the barrier to entry, hook users into the ecosystem).
  • Individual Pro: $3 / month recurring (Affordable, impulse-buy SaaS tier for freelance developers).
  • Team Expansion: +$1 / month per additional seat/team member (Scales automatically with agency growth).

End-to-End Encrypted (E2EE) Sync Architecture

The Sync Cloud operates as a Zero-Knowledge Relay.

  • The local SQLite database (Vault) is symmetrically encrypted using AES-256-GCM via Argon2id Key Derivation.
  • Sync payloads are heavily obfuscated blobs. The cloud never receives the Master Password or Data Encryption Key (DEK).
  • When a team member is added, Public-Key Cryptography (ECDH) is used to exchange vault access asynchronously without exposing secrets to the server.
