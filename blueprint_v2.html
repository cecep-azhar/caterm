1. Executive Summary & Genesis (Why Termius / Termique Fails Power Users)

Having used Termius and traditional SSH GUI tools for years across multi-device and multi-platform environments, several critical flaws degrade professional developer experience:

  • Extreme Memory Bloat: Electron-based SSH clients consume 400MB to 1GB+ RAM per instance, draining laptop battery and lagging on lower-spec hardware.
  • Vendor Lock-in & Data Revocation: The moment a subscription ends, access to cloud configurations, host groups, custom snippets, and sync preferences is revoked or wiped out.
  • Incomplete Configuration Backup: Local exports fail to capture the entire environment context (known hosts, custom key bindings, environment variables, AI settings).
  • Privacy & Telemetry Risks: Kredensial dan metadata tersimpan di server pihak ketiga dengan enkripsi proprietary yang tidak terverifikasi independen.
CATerm Core Philosophy (5 Pillars):
1. Very Light: Tauri 2.0 (Rust) + System Webview → < 35MB RAM usage, < 8MB binary.
2. Stable: SQLite WAL Mode + Native Rust Async PTY Engine (`russh`). Zero panic, 100% thread-safe.
3. Privacy First: Zero-Knowledge E2EE (Argon2id + AES-256-GCM). Key lokal tidak pernah keluar tanpa enkripsi.
4. Collaboration Next: Asymmetric E2EE Team Vault sharing via ECDH (Curve25519) + $1/month team seats.
5. Sync Next: Self-Hostable or Managed Sync Cloud ($1 month 1, $3/mo recurring). Jika langganan habis, DATA LOKAL TETAP 100% UTUH & BERFUNGSI SELAMANYA!

3. Catatan Khusus Phase 2: Sync Cloud & Team Infrastructure Strategy

Catatan Khusus Arsitektur Phase 2 (Sync Cloud & Collaboration):

Untuk mempertahankan integritas filosofi Open-Source dan kebebasan pengguna, seluruh fitur Multi-Device Sync dan Team Collaboration di dalam repositori publik CATerm v2 akan dipasang dalam kondisi DISABLED / NEXT FEATURE (Mode Placeholder UI Cantik).

A. Model Monetisasi Official Cloud:

  • Trial Onboarding: $1 untuk bulan pertama (Memvalidasi pengguna serius dan menutupi biaya verifikasi payment gateway).
  • Managed Cloud Individual: $3 / bulan berikutnya (Harga sangat terjangkau dibanding Termius $10+/bln).
  • Team Collaboration Seats: +$1 / bulan per anggota tim tambahan.

B. Desain Infrastruktur Cloud yang Akan Disiapkan Cecep Azhar:

  • Infrastruktur Core: Node backend Microservice (Go/Rust) yang dideploy di atas **Coolify / FathCloud** (Hostinger VPS & DigitalOcean).
  • Zero-Knowledge Storage Engine: Server sync HANYA menyimpan *encrypted SQLite blob* (AES-256-GCM). Server TIDAK PERNAH memiliki kunci enkripsi (Master Password / DEK).
  • Asynchronous Team Sharing (ECDH): Setiap pengguna memiliki pasangan kunci publik/privat Curve25519. Kredensial grup server dienkripsi menggunakan *shared secret* ECDH anggota tim sebelum diunggah.
  • Self-Host Option vs Managed Official Cloud: Kode server backend sync juga akan dibuat *lightweight* (Docker Container) sehingga komunitas dapat melakukan *self-hosting* gratis, sementara pengguna biasa dapat berlangganan Official Managed Cloud seharga $3/bln.
